## 💡 Why This Project Matters

Unlike a tutorial clone or solo side project, **Lulu Furniture is a live, in-production website built for an actual paying client** in the furniture retail space. It required translating real design files into a performant, responsive, deployed product — with a custom domain and SSL that's live today serving real customers.

> **For recruiters & hiring managers:** this project shows I can take ownership of a client's frontend from design handoff to deployment, communicate scope, and ship something that holds up in production — not just in a portfolio.

---

## 👨‍💻 My Role

This was a freelance/contract engagement where I owned the entire frontend build:

- Built the complete frontend from client-provided designs
- Designed reusable React components used consistently across multiple pages
- Implemented responsive layouts for mobile, tablet, and desktop
- Optimized images and layout structure to improve load performance
- Deployed and maintained the app on Vercel with a custom domain + SSL
- Debugged and resolved cross-browser UI inconsistencies

## ⚙️ Run It Locally

```bash
# Clone the repository
git clone https://github.com/mohammedrayyan-dev/Lulu-Furniture.git

# Move into the project folder
cd Lulu-Furniture

# Install dependencies
npm install

# Start the development server
npm run dev
```

App runs locally at **http://localhost:5173**
